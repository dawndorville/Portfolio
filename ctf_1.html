Breach at the Beach

A security challenge with a world of its own.

Breach at the Beach is a highly technical story-driven Capture the Flag game created by Varonis Threat Labs that drops security practitioners into a real-world cloud identity breach investigation.

Reach 2,356 total players in the first 3 months
Completion 64 teams completed the 4+ hour game
Total submissions 18,957 recorded submissions across all levels

Scene and character development

This scene establishes the game’s world: Pixel, the VTL team mascot and threat hunter, is visiting the beach when a storm rolls in. I created the individual elements as SVGs, then used Claude Code to translate my visual direction into the CTF’s scene transition, shaping the timing, animation, and effects together.

The approach

Combine hand-crafted characters with a repeatable production workflow.

I drew the characters pixel by pixel. For more complex scenery, I used Nano Banana and a Figma Make tool I created to convert imagery into vectorized pixels with SVG downloads.

01

Draw the characters

Pixel the cat was brought over from a previously created game. Additional hand-created pixel characters establish the personality and detail of the game world.

02

Generate the scenery

I created stylized scenery with a set color palette in Figma Weave using Nano Banana, rapidly creating background elements for the scenery.

03

Build a conversion tool

I created a custom Figma Make program allowing me to upload rasterized image for conversion to vectorized pixels with an adjustable scale. The vector could then be downloaded as an SVG for editing.
